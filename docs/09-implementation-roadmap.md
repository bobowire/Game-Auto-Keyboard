## 风险管理

### 高风险项

#### 1. PostMessage 兼容性
**风险**: 目标程序不响应 PostMessage  
**缓解**: 
- 阶段1就实现测试工具
- 提供 SendInput 备选方案
- 文档说明兼容性限制

#### 2. 热键冲突
**风险**: 热键被其他程序占用  
**缓解**:
- 注册失败时清晰提示
- 允许自定义热键
- 提供备用热键方案

#### 3. 窗口句柄失效
**风险**: 窗口关闭后 HWND 失效  
**缓解**:
- 每次发送前检查 `IsWindow`
- 失效后自动停止执行
- UI 显示窗口状态

### 中风险项

#### 1. 脚本解析错误
**风险**: 复杂语法解析失败  
**缓解**:
- 充分单元测试
- 清晰的错误提示
- 提供语法检查工具

#### 2. 截图性能问题
**风险**: 频繁截图导致卡顿  
**缓解**:
- 区域截图而非全屏
- 缓存机制
- 可配置查找频率

   ```bash
   cargo new game-auto-keyboard
   cd game-auto-keyboard
   ```

3. **创建目录结构**
   ```bash
   mkdir -p src/{script,input,executor,hotkey,window,scheme,ui,utils}
   ```

   - 创建 `src/script/ast.rs`
